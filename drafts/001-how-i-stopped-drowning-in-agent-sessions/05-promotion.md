### Post

I run enough coding-agent sessions in parallel that I can forget what one is
for on the same afternoon I started it.

Four of their titles began with “Build & publish.” Their worktrees arrived as
`goofy-mclaren-e45a74`. Every name looked specific. None helped.

I thought I needed better names.

I was wrong.

The solution came from a knowledge graph built with pen and paper.

Doing it by hand takes seconds. Automating it was a more interesting challenge.
It revealed something I had not expected: coding agents are vibe coded too.

I wrote about the paper system, the one rule behind it, and what the automation
exposed about the tools themselves.
