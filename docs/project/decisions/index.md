# Decision Records

Decision records preserve consequential choices that would otherwise be
reopened or forgotten.

Each decision owns one file under `records/` and carries its lifecycle in
frontmatter. Valid states are `Open`, `Decided`, `Superseded`, and `Dropped`.
Update the same record when its state changes; do not move records between
status directories.

- `2026-08-08T0223Z-first-article-editorial-choices.md` — Open
