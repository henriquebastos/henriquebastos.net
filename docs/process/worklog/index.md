# Worklog

The worklog records meaningful completed milestones. Each entry owns one file
under `entries/` and uses a UTC timestamp in its filename:

`YYYY-MM-DDTHHMMZ-author-short-slug.md`

Do not append milestone history to this index. A completed editorial handoff
entry should record:

- what became accepted and canonical;
- why the milestone matters;
- verification performed and evidence inspected;
- Navigator acceptance separately from Driver QA;
- conscious exclusions, deferred choices, and the next owner/action.
